# Outside the Box website

Static homepage and privacy policy prepared for GitHub Pages.

## Publishing

1. Push the contents of this directory to the `main` branch of `palashparate009/outside-the-box-game-site`.
2. In GitHub, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.

The resulting URLs normally follow this pattern:

- Homepage: `https://palashparate009.github.io/outside-the-box-game-site/`
- Privacy: `https://palashparate009.github.io/outside-the-box-game-site/privacy.html`

For Google OAuth production verification, GitHub Pages may not satisfy the requirement for a verified domain you own. A custom domain attached to GitHub Pages is recommended for final OAuth brand verification.
